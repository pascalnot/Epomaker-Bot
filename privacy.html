Privacy Policy

Last updated: June 2026

1. Overview

Epomaker Bot is used only within a single Discord server to provide automated support responses and basic utility functions.

2. Data Processed

The bot may process:

  • Discord user IDs
  • Discord server ID
  • Discord channel ID
  • Command messages (e.g. !help, !support)

No additional personal data is collected.

3. Purpose

Data is processed only to:

  • Respond to commands
  • Provide support information
  • Maintain bot functionality
  • Prevent abuse or misuse

4. Message Content

Message content is only read when required to detect and respond to bot commands.

It is not stored or used for any other purpose.

5. Data Storage

The bot does not permanently store user messages or personal data.

6. Data Sharing

No data is shared, sold, or transferred to third parties.

7. Data Access and Deletion

As the bot is used in a single server environment, any data concerns can be addressed directly through the server administrators.

8. Third Parties

The bot operates through Discord and is subject to Discord’s Privacy Policy:

https://discord.com/privacy

9. Contact

Contact server moderators for any questions regarding data handling.
